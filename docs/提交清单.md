## 加分项

- AI 原始响应、proposal、人工 final payload 分离保存。
- 人工确认、修改确认、拒绝均可审计，重复审核被拒绝。
- 页面分别提供“采用初稿”“保存修改并采用”“不采用”，审核后对照显示纪要初稿与最终结果。
- 同一 12 例真实 baseline/optimized 评测；optimized 本次 12/12。
- 提示注入、来源回指、重复合并、确定性日期、乐观锁与事务回滚。
- 响应式 Web 工作台；具体供应商与模型名不出现在日常界面，生成服务不可用时手工流程继续可用。

## 提交前命令

```powershell
.\test.ps1
python scripts\verify_submission.py --strict-clean
```

严格检查必须在清理后的提交副本中通过。普通模式会提示测试产生的本地运行物但不破坏 `test.ps1`；`--strict-clean` 会把这些运行物判为失败。禁止提交真实 `DEEPSEEK_API_KEY`、`.env`、本地数据库、`__pycache__`、`.pyc`、虚拟环境或测试临时目录；不要通过删除检查或放宽密钥规则来“通过”。

现场展示顺序以 `docs/演示脚本.md` 为准；默认启动地址为 <http://127.0.0.1:8766>，不要误开被其他服务占用的 8000。

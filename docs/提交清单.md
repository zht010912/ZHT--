# 任务一提交清单

## 必做项映射

| 任务要求 | 实现位置 | 验证证据 |
|---|---|---|
| 会议新增、列表、详情、删除、筛选、持久化 | `meeting_assistant/web.py`、`db.py` | 删除二次确认、级联与重启持久性测试；浏览器验收 |
| 行动项新增、编辑、完成、筛选、持久化 | `web.py`、`db.py`、前端工作台 | 页面新增/编辑/勾选/刷新；API/数据库测试 |
| 3 场会议、8 条行动项 | 幂等种子数据 | 首次启动工作台统计 |
| 摘要、决策、行动项、负责人、日期、原文来源 | `ai.py`、`guardrails.py` | Mock 单测与 12 例真实评测 |
| 不确定项标待确认 | 确定性后处理 | 无负责人/模糊日期测试 |
| AI 建议不自动生效 | analysis run + review 事务 | confirm/edit/reject 测试 |
| 输出校验与失败降级 | Pydantic、错误映射、失败审计 | 无 Key、401、429、5xx、超时、坏 JSON 测试 |
| 至少 6 条测试 | `tests/` 共 45 条 | `45 passed` |
| 至少 6 项风险、3 项加固 | `docs/风险与加固清单.md` 共 17 项 | 自动化、浏览器、真实模型证据 |

## 加分项

- AI 原始响应、proposal、人工 final payload 分离保存。
- 人工确认、修改确认、拒绝均可审计，重复审核被拒绝。
- 页面分别提供“直接确认原始建议”“保存修改并确认”“拒绝建议”，审核后对照显示原始建议与最终结果。
- 同一 12 例真实 baseline/optimized 评测；optimized 本次 12/12。
- 提示注入、来源回指、重复合并、确定性日期、乐观锁与事务回滚。
- 响应式 Web 工作台；DeepSeek 不可用时手工流程继续可用。
- 会议删除采用专用确认框、事务级联和一次性样例初始化标记，避免误删与重启复活。
- Windows 安装版使用 PyInstaller + Inno Setup 打包；会议数据与可选 AI 配置位于用户目录，不随安装包携带 Key。

## 提交前命令

```powershell
.\test.ps1
python scripts\verify_submission.py --strict-clean
```

严格检查必须在清理后的提交副本中通过。普通模式会提示测试产生的本地运行物但不破坏 `test.ps1`；`--strict-clean` 会把这些运行物判为失败。禁止提交真实 `DEEPSEEK_API_KEY`、`.env`、本地数据库、`__pycache__`、`.pyc`、虚拟环境或测试临时目录；不要通过删除检查或放宽密钥规则来“通过”。

现场展示顺序以 `docs/演示脚本.md` 为准；默认启动地址为 <http://127.0.0.1:8767>，不要误开被其他服务占用的 8000。
